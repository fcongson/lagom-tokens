# @fcongson/lagom-brands

## 1.0.0

First release: **Fern** (the look lagom-tokens 1.x shipped) and **Waypoint**, each with light, dark, and increased-contrast values, built on `@fcongson/lagom-tokens` 2.0.0. Load a brand's `css/<brand>.css` after `lagom.css` and set `data-lagom-brand` on `<html>`.
